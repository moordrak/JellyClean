Prvo izdanje napravljeno automatski preko GitHub Actions.

## Promjene
- Releasei se od sada kreiraju sami kad se na `main` podigne `APP_VERSION` u `app.py`
- Uz arhive i `create-lxc.sh` sada se objavljuje i `SHA256SUMS`

Funkcionalnost je ista kao u v1.0.0.

## Instalacija na Proxmox (novi LXC)
```bash
bash -c "$(curl -fsSL https://github.com/moordrak/JellyClean/releases/latest/download/create-lxc.sh)"
```
