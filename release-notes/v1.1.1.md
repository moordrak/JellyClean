## Popravak nadogradnje

`pct exec <ID> -- jellyclean-update` je javljao *Failed to exec "jellyclean-update"* kad je instalacija stala prije koraka koji postavlja updater.

- **`jellyclean-update`** sada radi i bez gita: ako kod nije instaliran gitom, preuzme najnoviji release preko GitHub API-ja (`GH_TOKEN=…` za privatni repozitorij). Na kraju provjeri je li se servis podigao i ispiše npr. `1.1.0 → 1.1.1`.
- **`create-lxc.sh`** postavlja updater odmah nakon instalacije koda, pa postoji i ako kasniji korak ne uspije. Upute koriste punu putanju `/usr/local/bin/jellyclean-update`.
- **Novo: `update-lxc.sh`** za Proxmox host. Sama pronađe JellyClean kontejnere (po tagu ili hostnameu), u svaki postavi ili osvježi updater i nadogradi ga.

## Nadogradnja postojećeg kontejnera (na Proxmox hostu)
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/moordrak/JellyClean/main/proxmox/update-lxc.sh)"
```
Ako javi da u kontejneru nema `/opt/jellyclean/app.py`, instalacija se nikad nije dovršila. Tada kontejner obriši (`pct stop <ID>; pct destroy <ID>`) i instaliraj ponovno.

## Novi LXC

```bash
bash -c "$(curl -fsSL https://github.com/moordrak/JellyClean/releases/latest/download/create-lxc.sh)"
```
