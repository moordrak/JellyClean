## Instalacija u whiptail prozorima

`create-lxc.sh` sada vodi kroz instalaciju u **pravim dijaloškim prozorima** (whiptail), kao poznate Proxmox helper skripte:
- na početku je **ASCII logo** JellyCleana
- na vrhu ekrana stoji trenutni korak (**Korak x/7**): Kontejner → NFS shareovi → Jellyfin API → Jellyfin config (SSH) → Postavke → Kreiranje i otkrivanje → Instalacija
- izbornici i popisi se biraju strelicama, a stavke označavaju razmakom
- API ključ, sudo lozinka i token unose se u skrivena polja
- *Odustani* uvijek pita prekidaš li instalaciju ili nastavljaš na istom pitanju
- dulji poslovi (kreiranje kontejnera, instalacija paketa, montiranje, otkrivanje) ispisuju napredak u konzoli
- na kraju se prikaže prozor sa sažetkom (adresa, prijava, mape), a isti sažetak ostaje ispisan u konzoli

Prozori se sami prilagođavaju veličini terminala. Dulji tekstovi se mogu pomicati.

### Bez prozora
Ako ti prozori ne odgovaraju (npr. u nekim web konzolama), cijela instalacija radi i u običnoj konzoli:
```bash
NO_WHIPTAIL=1 bash create-lxc.sh
```
Isto se događa automatski kad whiptail nije dostupan.

## Instalacija na Proxmox (novi LXC)
```bash
bash -c "$(curl -fsSL https://github.com/moordrak/JellyClean/releases/latest/download/create-lxc.sh)"
```
