## Jellyfin config: jasnija pločica „Jellyfin data mapa”

Pločica „Baza i ostali podaci” pokazivala je veličinu cijele `data` mape kao da je sve baza, iako je u toj mapi i `metadata`, koja je obično najveća. Sada:
- pločica se zove **Jellyfin data mapa** i pokazuje zbroj, a ispod njega posebno **bazu**, **metadata** i **ostalo**
- tablica navodi sve podmape (metadata, trickplay, keyframes, subtitles, attachments, plugins…) od najveće, s kratkim opisom svake
- baza je zbroj `*.db` datoteka zajedno s `-wal` i `-shm`, označena kao „ne dirati”
- kad trickplay ili keyframes zauzimaju puno, prikaže se savjet kako ih isključiti u Jellyfinu

## Pomoćni program na Jellyfin računalu
- `jellyclean-helper` sada ima verziju. Ako je na VM-u stariji, JellyClean to prikaže upozorenjem.
- **`update-lxc.sh`** nakon nadogradnje sam provjeri verziju pomoćnog programa. Ako je zastario, traži sudo lozinku SSH korisnika i osvježi ga. Lozinka se ne sprema, a Enter preskače.

## Nadogradnja (na Proxmox hostu)
```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/moordrak/JellyClean/main/proxmox/update-lxc.sh)"
```
