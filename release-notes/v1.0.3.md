## Popravci

### Jellyfin API ključ nije prihvaćen (Jellyfin 12)
Jellyfin 12 je isključio zastarjeli header `X-Emby-Token`. Zato je skripta odbijala i ispravan API ključ (HTTP 401), a isto bi se dogodilo i kod otkrivanja biblioteka. Skripta, otkrivanje i aplikacija sada šalju ključ ispravno, kao `Authorization: MediaBrowser Token="…"`.

- Ključ se čisti od razmaka i novih redova (često nastanu pri kopiranju), a nakon unosa se prikaže njegova duljina.
- URL upisan bez `http://` automatski se dopuni.
- Kad Jellyfin odbije ključ, poruka objašnjava što provjeriti, uključujući nginx i prosljeđivanje headera `Authorization`.

### `create-lxc.sh` bez dijaloških prozora
Sva pitanja sada idu izravno u konzolu:
- izbor brojem (npr. `2`)
- više stavki odjednom: `1 3`, `sve` ili `nista`
- potvrde s `d`/`n`, a Enter prihvaća ponuđeno u zagradama
- API ključ, lozinka i token se pri upisu ne prikazuju

## Instalacija na Proxmox (novi LXC)
```bash
bash -c "$(curl -fsSL https://github.com/moordrak/JellyClean/releases/latest/download/create-lxc.sh)"
```
Ako je prethodni pokušaj već kreirao kontejner, prvo ga obriši: `pct stop <ID>; pct destroy <ID>`.
