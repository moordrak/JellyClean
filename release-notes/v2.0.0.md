## JellyClean v2.0.0: više Jellyfin servera

### Novo
- **Kartica Serveri:** dodavanje, uređivanje, provjera veze i uklanjanje Jellyfin servera. Svi koriste iste medije, a svaki ima vlastiti URL, API ključ, PATH_MAP i SSH pristup.
- **Izbornik servera u zaglavlju:** kartice Jellyfin, Provjera putanja, Jellyfin config i Test enkodiranja (s nadzorom kartice i NVENC patchem) prikazuju odabrani server.
- **Postavljanje pristupa jednom naredbom:** JellyClean daje `curl … | sudo sh` naredbu za računalo s Jellyfinom. Ona:
  - doda SSH ključ
  - pronađe Jellyfin (Docker ili paket) i njegove mape
  - postavi pomoćni program sa sudo pravilom samo za njega

  Poveznica vrijedi 30 minuta, a lozinka se ne sprema.
- **Provjeri vezu:** provjerava Jellyfin API i SSH, sama preuzima putanje i verziju pomoćnog programa i upozori ako je zastario.
- Nakon brisanja ili vraćanja iz kante JellyClean javlja promjenu svim serverima, a automatska sinkronizacija obuhvaća sve servere.

### Kompatibilnost
- Postojeća instalacija radi kao i prije. Server iz `/etc/jellyclean.env` postaje **glavni server**.
- Izmjene glavnog servera u sučelju imaju prednost pred env datotekom, a **Vrati iz env** ih poništava.
- Pomoćni program prelazi na **verziju 10** (dodane operacije `paths` i `detect`). Na glavnom serveru ga nadograđuje `update-lxc.sh`, a na ostalima naredba iz **Postavi pristup**.
- Na užim ekranima gumb za skeniranje prikazuje samo ikonu ↻, da zaglavlje stane u jedan red.
