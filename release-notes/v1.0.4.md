## Jellyfin config preko SSH-a bez root korisnika

SSH korisnik na Jellyfin računalu više ne mora biti `root` niti imati sudo bez lozinke.

`create-lxc.sh` sada:
- **prvo provjeri** ima li korisnik već prava na `cache`, `log` i `metadata`, što je čest slučaj kod linuxserver imagea s `PUID` jednakim UID-u korisnika. Ako ima, sudo nije potreban.
- ako treba root (npr. za `docker inspect` ili kad mape pripadaju drugom korisniku), **sudo lozinku pita jednom**. Lozinka se koristi samo tijekom postavljanja i nigdje se ne sprema.
- postavlja **ograničeni pomoćni program** `/usr/local/sbin/jellyclean-helper` i sudoers pravilo provjereno s `visudo`. Korisnik bez lozinke smije pokretati **samo** taj program, a on zna samo mjeriti mape i brisati cache, stare logove i siročad u metadata, i to samo u svojim putanjama. JellyClean tako nema potpuni root na tom računalu.

Aplikacija i pomoćni program koriste isti kod, pa rade jednako u svim načinima: izravno, preko pomoćnog programa ili uz potpuni sudo.

Popravljena je i lažna dojava greške pri provjerama u skripti (`grep -q` u kombinaciji s `pipefail`).

## Instalacija na Proxmox (novi LXC)
```bash
bash -c "$(curl -fsSL https://github.com/moordrak/JellyClean/releases/latest/download/create-lxc.sh)"
```
Ako je prethodni pokušaj već kreirao kontejner: `pct stop <ID>; pct destroy <ID>`.

Pomoćni program se uklanja s Jellyfin računala ovako: `sudo rm /usr/local/sbin/jellyclean-helper /etc/sudoers.d/jellyclean`
